# Task Assignment & Tracking

## 📌 Project Description

Task Assignment & Tracking is a web-based application developed to manage employees, assign tasks, and track task progress efficiently.

The system allows an HR user to manage employee information, create and assign tasks, set priorities and due dates, and update task status.

## 🎯 Objectives

- Manage employee information
- Assign tasks to employees
- Set task priority and due dates
- Track task status
- View employee and task information through a dashboard
- Reduce manual task management

## ✨ Main Features

- 🔐 HR Login
- 👩‍💼 Employee Management
- 📋 Task Management
- ➕ Add Employee
- ➕ Add Task
- 🔄 Task Tracking
- 📊 Dashboard
- 📈 Reports
- 🔔 Notifications
- 🚪 Logout

- Pending
- In Progress
- Completed
